# IT313 Enrollment Eligibility Checker

## Problem
This program processes student grades and determines
whether each enrollee is PASSING or on PROBATION.

## Approach
- Compute the average of three grades.
- Use a separate module for grade calculations.
- Simulate retrieving student data using a Promise.
- Process records using map, filter, and reduce.
- Display a formatted eligibility report.
- Handle errors using async/await and try/catch.

## Requirements
- Node.js
- A code editor such as Visual Studio Code

## How to Run
1. Open the project folder in VS Code.
2. Open the terminal in the project folder.
3. Run npm start.

## Files
- gradeUtils.js: Grade calculation and eligibility functions.
- main.js: Data processing and report generation.
- package.json: Node.js module configuration.
